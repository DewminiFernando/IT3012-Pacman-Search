# IT3012 - Pac-Man Search

## Module
**IT3012 - Intelligent Agents**

## Assignment
**Group Assignment - Search Algorithms in Pac-Man**

## Project Overview

This project is based on the Pac-Man search framework provided for the IT3012 group assignment.

The objective of the assignment is to implement and evaluate classical search algorithms and heuristics in the Pac-Man environment.

The main tasks are:

- Depth-First Search (DFS)
- Breadth-First Search (BFS)
- Uniform Cost Search (UCS)
- A* Search
- Corners Problem
- Corners Heuristic
- Food Search Heuristic

The assignment requires the use of the provided data structures and Pac-Man framework files.
